# 农作物 Agent — UI 设计风格规范

> **版本**：v1.0 ｜ **更新日期**：2026-08-17 ｜ **定位**：智慧农业 × AI Agent

---

## 设计风格定位

**自然生长 · 智慧感知 · 温润可信赖**

整体视觉从农田、土壤、作物中提取色彩与形态语言，避免冰冷的纯科技感。界面保持克制、简洁，让农业从业者"看得懂、用得顺"。

---

## 色彩体系

| 角色 | 色值 | 说明 |
|------|------|------|
| 主色·田野绿 | #3D8B37 | 品牌色、主按钮、导航激活态 |
| 辅色·麦穗金 | #E8B930 | 核心 CTA、重要数据高亮 |
| 辅色·土壤棕 | #8B6F47 | 卡片背景辅助、装饰元素 |
| 辅色·天空蓝 | #4A9BD5 | 数据面板、信息提示 |
| 成功 | #3D8B37 | 健康状态 |
| 警告 | #E8B930 | 需关注 |
| 错误 | #D9534F | 病虫害、操作失败 |

**背景色**：页面底色 #FAFBF9，卡片底色 #FFFFFF，不使用纯黑背景。

---

## 间距与圆角

- **间距基数**：4px，常用 8 / 12 / 16 / 24 / 32px
- **圆角**：小元素 6px，卡片 16px，按钮/胶囊 9999px
- **阴影**：卡片默认轻阴影，hover 时加深

> 圆角偏柔和，呼应种子、果实的有机形态。

---

## 核心组件

### 按钮

- **主按钮**：绿底白字，胶囊形
- **高亮 CTA**：金底深棕字，用于"开始诊断""生成方案"等
- **次级按钮**：灰底描边
- **危险按钮**：红底白字，用于删除等操作

### Agent 对话区

- Agent 气泡：浅绿底，左对齐，左上角圆角特殊处理
- 用户气泡：主色绿底白字，右对齐
- 思考中：三颗绿色圆点呼吸动画
- 快捷指令：胶囊形芯片按钮

### 卡片

- 白底 + 轻边框 + 轻阴影
- hover 时微微上浮 + 阴影加深
- 作物状态用彩色标签区分（健康/预警/病害）

---

## 图标与插画

- **图标风格**：线性为主，圆角端点，1.5px 线宽
- **插画风格**：扁平 + 微质感，色调取自色彩体系
- **空状态**：种子等待发芽的插画 + 引导文案

---

## 动效

- 过渡时长：150ms（hover）/ 250ms（卡片）/ 400ms（弹窗）
- 缓动曲线：cubic-bezier(0.4, 0, 0.2, 1)
- 特色动效：Agent 思考时圆点弹跳、数据加载时进度条"生长"动画
- 尊重系统"减弱动效"设置

---

## 响应式适配

| 端 | 策略 |
|----|------|
| 桌面 ≥1280px | 侧栏 + 内容区双栏 |
| 平板 768–1279px | 侧栏折叠为图标栏 |
| 手机 <768px | 底部 Tab 导航，卡片单列 |

移动端最小点击区域 44×44px，输入框高度 ≥ 48px。

---

## 无障碍

- 文字与背景对比度 ≥ 4.5:1
- 不仅靠颜色区分状态，辅以图标/文字
- 图标按钮提供 aria-label
- 支持键盘 Tab 导航

---

> **一句话总结**：让用户感觉不是在使用一个"软件"，而是站在一片有智慧、有温度的数字农田里。
